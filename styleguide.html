Brand signal

brand · acid-lime
--brand #C6FB5A
Usage

The brand color is a signal, not a background. Use it sparingly — primary CTAs, active-state indicators, focus rings, key data points on charts. Never color large surfaces with it. In light mode, brand ink inverts: ink becomes primary, lime becomes the accent on inverted buttons.

Navigation pattern

260px fixed · grouped sections
Anatomy
  • Brand lockup — mark + wordmark, always left-aligned top
  • Command search — single entry, keyboard-hinted (⌘K)
  • Grouped nav — uppercase mono labels separate Workspace, Scanners, Admin
  • Active state — lime 2px rail at item's left edge + raised surface
  • Count chips — mono numerals; criticals carry red tint
  • User footer — avatar + role, persists across all screens
Rules
  • Max 5 items per group — flatten before you nest
  • Icons always paired with label — never icon-only in primary nav
  • Counters only on active work (open findings) — never decorative

Principles

the why behind the what
01

Signal, not decoration

Color earns its place. Severity hues, brand lime, and state greens communicate. Everything else is grayscale. If a color doesn't change a decision, it shouldn't be there.

02

Dense but breathable

Operators scan. Tables, cards, and charts pack information tightly, but every cluster is bounded by negative space and a soft border. No walls of text.

03

Mono speaks data

Anything machine-produced — CVEs, versions, hashes, timestamps, counts — renders in JetBrains Mono. The eye learns: mono = fact, sans = human.
